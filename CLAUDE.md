# CLAUDE.md — правила проекта `metacognitive_therapy_wells`

**date-create:** 2026-10-24 17:45

## О проекте
Личное веб-приложение по протоколу метакогнитивной терапии (Adrian Wells) при ГТР. Полная спецификация — в `SPEC.md`. Перед любой работой читай `SPEC.md`.

## Общение
- Отвечай на русском. Пользователь — начинающий программист: объясняй просто, без лишнего жаргона, ошибки переводи на русский.
- Делай только то, что попросили. Без непрошеных рекомендаций и «лучших практик».
- Если задача неоднозначна — остановись и задай вопросы, не додумывай.
- После выполнения задачи предложи следующий шаг.
- Экономь токены: не читай большие файлы и папки целиком без необходимости.

## Технические правила
- Стек: SvelteKit + SQLite (`better-sqlite3`) + OpenAI API, см. `SPEC.md` раздел 3. Менять стек только по явному согласию пользователя.
- Секреты только в `.env`. `.env` в `.gitignore`. Никогда не коммить ключи и токены. В репозиторий кладётся `.env.example` с пустыми значениями.
- Ключ OpenAI используется только на сервере, никогда не передаётся в браузер.
- Тексты этапов и промпты — в `content/`, не в коде.
- Все тексты этапов писать своими словами. Не копировать текст из книг Уэллса и Каллесен.
- Не удалять и не перезаписывать существующие файлы без явного разрешения.
- Интерфейс на русском.

## Git
- Ветки: `feature/`, `bugfix/`, `hotfix/`.
- Коммиты: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`.

## Документация
- В начале каждого документа: `**date-create:** YYYY-MM-DD HH:MM` (московское время).
- Обновления документов оформлять блоком:
  ```
  ---
  date-update: YYYY-MM-DD HH:MM
  [что изменилось]
  ---
  ```
- Перед коммитом обновлять все метки времени.

## Порядок работы
1. Прочитать `SPEC.md`.
2. Перед реализацией фазы — предложить короткий план (список файлов и шагов) и дождаться подтверждения.
3. Реализовывать по фазам из `SPEC.md` раздел 9. Не делать Фазу 2 до приёмки Фазы 1.
4. После каждого шага — коротко что сделано и как проверить.
