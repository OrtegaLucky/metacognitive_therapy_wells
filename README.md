# Дневник метакогнитивной терапии

**date-create:** 2026-11-23 14:10

Личное веб-приложение по протоколу метакогнитивной терапии (А. Уэллс) при ГТР. Полная спецификация — `SPEC.md`.

## Что нужно
- Node.js 22 или новее.

## Первый запуск (Ubuntu / WSL)

```bash
cd ~/projects_claude/metacognitive_therapy_wells
npm install
cp .env.example .env
npm run gen-key          # строку вставить в .env как DB_KEY=...
npm run hash-password    # строку PASSWORD_HASH=... вставить в .env
npm run dev
```

Открыть http://127.0.0.1:5173 и войти с паролем.

**Ключ `DB_KEY` сохраните отдельно** (например, в менеджере паролей). База зашифрована: без ключа данные не восстановить.

## Где что лежит
- `content/stages.json` — этапы: название, цель, задания, условия перехода.
- `content/stages/NN.md` — тексты этапов. Правятся без изменения кода.
- `migrations/` — схема базы. Новые файлы применяются автоматически при старте.
- `src/lib/server/` — база, вход, проверка условий перехода.
- `src/routes/` — экраны.
- `data/app.db` — зашифрованная база (не в git).

## Запуск на сервере
Будет описан при настройке деплоя на main-сервер (SPEC 12.1): сборка `npm run build`, запуск `npm start` за nginx.
